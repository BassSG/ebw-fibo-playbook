# EBW-Fibo × All-Indy — สถานะการตรวจสอบ

**ประกาศแก้ไข:** เว็บไซต์เวอร์ชันก่อนมี Win Rate, Profit Factor, Drawdown และอันดับไทม์เฟรมที่ไม่ได้เกิดจากแบ็กเทสต์จริง ตัวเลขเหล่านั้นถูกถอนแล้ว ห้ามใช้ประกอบการเทรด

[เปิดเว็บสถานะล่าสุด](https://basssg.github.io/ebw-fibo-playbook/)

- `index.html` — หน้าแจ้งสถานะหลักฐาน (รอผลตรวจจริง)
- `ebw_fibo_source.pine` — **ไฟล์ไม่ครบ**: ผู้ช่วยคัดลอกข้อความของ EBW-Fibo 1.10.9 มาเพียง 632 บรรทัดและสิ้นสุดที่ `f_method` ไม่ใช่ซอร์สที่ใช้งาน/คอมไพล์ได้ ห้ามนำไปทดสอบแทนไฟล์จริง
- `EBW_Fibo_Audit_Report.md` — รายงานเดิมอ้างอิงไฟล์ไม่ครบ 632 บรรทัดเท่านั้น ไม่ใช่การรับรองระบบเต็ม และไม่มีสถิติผลงานจริง

ไฟล์ที่ผู้ใช้แนบเพิ่มเติมเป็น All Indy 1.2.4 และ EBW-Fibo 1.10.6; งานเปรียบเทียบสามรูปแบบรอ EBW-Fibo **1.10.9 ฉบับเต็ม** ตามที่ผู้ใช้เลือกก่อนเริ่มทดสอบและประกาศผล
